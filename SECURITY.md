# Security Policy

This service processes operational data and model-generated plans. Prompt-injection bypasses, unsafe tool execution, citation spoofing, audit-log exposure, secrets leakage, and approval-gate failures should be reported privately.

Use GitHub's **Security → Report a vulnerability** flow when available. Otherwise, contact the maintainer through the GitHub profile. Share sanitized inputs and outputs only; never include production credentials, customer data, or confidential incident logs.

The current `main` branch is supported. The project is a reference implementation and requires deployment-specific authentication, authorization, network isolation, secret storage, and retention controls.
